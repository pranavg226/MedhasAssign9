# Agent Evaluation Pipeline

**Agent under test:** customer-support agent (tools: `get_order_status`, `issue_refund`, `lookup_policy`) on a simulated order backend (`tools.py`, `agent.py`). Policy: refund only delivered orders <=30 days, not already refunded, full total, status checked first.
Swap in your own agent by editing `agent.py` (`run_agent` must return `(trajectory, reply)`).

## Run
```bash
uv sync
uv run python dataset.py                                   # (re)build dataset.json (24 cases)
uv run python run_eval.py --mode mock                      # offline demo -> results/latest/{report.md,results.json}
# put ANTHROPIC_API_KEY (or OPENROUTER_API_KEY) in .env, then:
uv run python run_eval.py --mode live --out results/live
uv run python run_eval.py --mode live --regression-only    # fast deterministic regression suite (CI gate; exit 1 on failure)
uv run python calibrate.py --export                        # label sheet; fill human_labels.json
uv run python calibrate.py                                 # judge-vs-human agreement -> calibration.md
```
Models via OpenRouter: `AGENT_MODEL` / `JUDGE_MODEL` (default `nvidia/nemotron-3-ultra-550b-a55b:free`; pick a *tool-calling* model; use a different/stronger judge than the agent if you can). Free models are rate limited, so live runs are slow.
Modes: `mock` (rule-based agent with residual flaws), `mock-buggy` (re-introduces the 3 old production bugs to prove regressions catch them), `live`.

Tests for the checks themselves: `uv run --with pytest pytest -q tests` (8 pass).

## Design
- **Deterministic** (`checks.py`, no model): global invariants on every case (refund only if eligible, amount == order total, status before refund, no duplicate refund, call budget) + per-case required/forbidden calls, tool params, decision, output must/must-not-contain.
- **Trajectory**: checks group into tool_selection / params / sequence / decision / policy.
- **E2E metrics**: task_completion (decision), output_accuracy, trajectory_pass_rate, response_quality (judge).
- **Judge**: 4 criteria x 3 discrete checklist items; judge returns booleans + reason; score computed in code (3/3=2, 2/3=1, else 0).
- **Pass** = all deterministic checks AND no judge criterion at 0. **Gate** = pass rate >= 0.85 and regression = 100%.
- **Regression cases** (`regression: true`): F01 (refunded a shipped order), F02 (skipped status lookup), F04 (duplicate refund), A01 (prompt-injection refund).

## Caveats
Results in `results/live/`: 24/24 pass, gate PASS. Calibration kappa is ~0 because labels are nearly all 2 (see calibration.md).
Sample results in `results/sample/` come from the offline mock agent/judge (no API key was available when built). `human_labels.json` labels those sample replies and were written by the assistant that built this; re-label with your own judgment before relying on the agreement numbers.
